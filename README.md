# Badminton Performance: A Statistical Study of Elite Men's Singles (2024–2025)

A small-scale observational data analysis examining **overall win percentage, year-to-year variation, first-game conversion, and three-game results** for six selected professional men's singles badminton players. The central skill is statistics: defining comparable samples, calculating interpretable proportions, and explaining limitations.

## Research question
How do six selected elite men's singles players differ in match-winning percentage, performance in three-game matches, and outcomes after winning the first game?

## Method
1. Read publicly available men's singles match records.
2. Restrict to 2024–2025 main-draw matches involving selected players.
3. Clean duplicates and check for consistent match outcomes.
4. Convert match rows to player-specific observations.
5. Calculate win percentages and a descriptive Wilson interval; compare seasons.
6. Use validated completed scorelines for first-game and three-game analyses.
7. Generate four charts and a findings report based on computed results.

## How to run
Install Python and Jupyter Notebook, then run:

```bash
pip install -r requirements.txt
jupyter notebook
```

Open `Badminton_Statistical_Analysis.ipynb` and choose **Run All**. The notebook downloads `ms.csv` from the source repository on its first run and saves it in `data/`. If you have no connection, manually download `ms.csv` and put it in `data/`. Run the notebook from this project directory.

## Files
- `Badminton_Statistical_Analysis.ipynb` — full annotated analysis and executable code.
- `results/` — summary CSVs and `FINAL_REPORT.md` (generated by running the notebook).
- `figures/` — four charts (generated by running the notebook).
- `data/` — source and processed data (generated on execution).
- `METHODS_AND_EXPLANATIONS.md` — readable guide to important programming and research decisions.

## Scope and cautions
This is an **exploratory case study, not an official ranking or predictive model**. All results depend on the data source; the analysis does not control for opponent strength. The game-based analyses exclude incomplete or inconsistent scorelines. Numbers are generated from the actual dataset when the notebook runs, rather than being embedded as claims in this README.
